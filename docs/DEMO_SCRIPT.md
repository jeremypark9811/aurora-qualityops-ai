# 5분 시연 대본

주소: http://127.0.0.1:5000. 품질팀 역할 → 시연 센터 → 시연 데이터 초기화 확인 문구로 시작. 실제 운영 접수가 있으면 독립 시연 DB를 사용한다.

## 0:00–0:25 소개
품질 운영 개요: “W03 품질 판정과 공급 복구를 연결했습니다. 내부 DB 처리는 실제이며 위원회와 부서 회신은 역할을 바꿔 입력하는 모의 처리입니다.”

## 0:25–0:55 실제 데이터
원본 탐색에서 fin_ap_aging_ms와 sales_meeting_notes 검색. “파일명과 내용이 달라 컬럼으로 식별했습니다. 생산 480개 배치, 검사·클레임 165건이며 원본은 변경하지 않았습니다.” 사전·조인 문서 열기.

## 0:55–1:55 정상
접수 담당 / 접수 담당자 적용 → 시연 센터 정상 실행 → 타임라인 접수·조회·판단 펼치기 → AI 분석. “17,900 / 150,745 = 11.87%. 키가 없는 현재는 규칙 기반 분석입니다. 10% 이상이지만 회수 실행은 사람에게 남깁니다.”

품질위원회 / 위원회 검토자 적용 → 승인 사유 입력·승인 → 회수 진행과 부서 업무 생성 확인. 새로고침 후 상태 유지.

## 1:55–2:40 부서 영향
작업 센터 영업·생산 탭. 생산팀 역할 적용. 정상 재고 100, 순가용량 200, 기간 “2026-07 시연”, 기존 약속 보호 확인 후 완료. “원본 사실이 아닌 모의 확인입니다. 부족량 때문에 새 생산 검토 업무와 영업 배분안이 달라집니다.”

## 2:40–3:15 조건 변경
접수 담당 → 시연 센터 조건 변경. 접수 상세 전후 비교. “보도는 확정 검사가 아니므로 불량률은 유지합니다. 기존 회수 승인에 연결하고 보도 사실 확인을 긴급 작업으로 만듭니다.”

## 3:15–4:10 정보 부족
출하 고객 확인 부족 실행. “원본을 삭제하지 않고 시연 확인 보류를 적용했습니다. 실행은 멈추고 물류 작업이 생깁니다.” 물류팀 역할 → 원본 고객 매핑 검토 → 완료 회신 → 자동 재분석·요청 생성.

## 4:10–4:35 거절
위원회 역할 → 추가 조사 필요 사유·거절. 회수 미실행·품질 조사 작업 확인. 독립 거절 시나리오도 동일 로직이다.

## 4:35–5:00 확장·한계
확장 분석·감사 로그. “추적률은 보류/회신 후 판단을 바꾸고 반복 경보는 실제 작업을 만듭니다. 배치-주문 직접 연결·정상 제조 재고·생산 일정 부족은 확인 대상으로 남겼습니다.”

실제 화면과 음성 해설을 촬영하고 모의 처리를 장면마다 설명한다. 이 문서는 대본이며 영상 자체는 별도 촬영해야 한다.
