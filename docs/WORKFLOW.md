# 업무 흐름과 권한

1. SYSTEM 접수: 고객·제품·배치·발생일 검증. 신규 고객 주장은 확정 불량에 미포함.
2. SYSTEM 조회: 원본 생산·검사·출하와 기존 회수 상태. 파일명·레코드 식별자 저장.
3. AI/규칙 판단: 확정 수량/생산량, 확정 True 및 10% 이상 검증. AI는 선택적 설명.
4. HUMAN 의결: 품질위원회와 접수자와 다른 수행자만 승인/거절/추가 정보/보류. 사유 필수. 자료 변경·미확인 범위는 재분석.
5. SYSTEM 처리: 승인하면 회수·출하 보류 상태와 영업·생산·별도 원인 조사 작업, 재공급 계획 생성. 거절하면 회수 없이 조사. 부족하면 확인 작업.
6. SYSTEM 기록: 이전·이후, 시각, 수행자, 사유, 근거, 업무 ID 보존. 이후 같은 배치는 기존 승인에 연결.

클레임 상태: 신규 접수 → 데이터 확인 중 → 정보 확인 필요 또는 AI 분석 완료 → 승인 대기 → 승인/거절/추가 정보 요청/보류 → 회수 진행 또는 원인 조사 → 처리 완료.

재공급 계획은 생산 여력 확인 필요 / 공급 부족·납품 협의 필요 / 재공급 계획 검토 가능을 별도로 관리한다. 회수 승인 사실과 공급 복구 진행을 혼동하지 않는다.

물류 완료 회신은 실제 출하 ID 전체와 고객 코드를 대조해야 한다. 없는 출하·알려진 원본 고객과 충돌은 거부하며 회신 후 자동 재분석한다. 생산 완료 회신은 정상 재고·순가용량·기간·기존 약속 보호 확인이 필요하다. 부족하면 새 생산 검토 업무와 영업 대안이 생성된다.

추가 검사는 품질팀만 고유 검사 ID·확정 여부·수량·비중복 확인·사유를 입력하며 원본과 별도 시연 기록으로 저장한다. 검사 ID 재사용은 거부한다. 품질팀 종료는 배치의 미완료 업무가 없고 재공급 미확인·부족이 없을 때만 가능하다.
