# 영업·생산 영향

## 영업

승인 트랜잭션에서 고객 안내·영향 범위 확인과 납품 일정·대체 공급 협의 작업이 실제 생성된다. 원본 출하 고객·수량이 근거다. 생산팀 확인 후 공급 가능량과 고객별 부족량이 계획·영업 업무 내용에 반영된다. 부족하면 긴급 우선순위로 변경된다.

배분 기본값은 출하량 우선, 영업팀이 고객 코드 순으로 바꿀 수 있다. 공식 규정이 아닌 시연 가정이다. 원본 주문에 납기일이 없고 SBL↔SH 직접 연결이 없으므로 특정 주문 지연 일수를 만들지 않는다. 납품 확인·협의 대상으로 남긴다.

## 생산

승인 시 재공급·여력 확인 작업이 생성된다. 능력 스냅샷은 문맥으로 표시하지만 기간 단위가 없으므로 월 가용량으로 환산하지 않는다. Masil 재고도 Corevia 정상 재고로 쓰지 않는다.

생산 회신은 정상 재고·기존 약속 차감 후 순가용량·적용 기간·약속 보호 여부를 포함한다. 부족=max(필요 교체량−정상 재고−순가용량,0), 회신 전에는 NULL이다. 부족이면 생산 일정 재검토 작업이 새로 생기고 영업 대안도 갱신한다. 공급 부족 또는 미확인 상태는 업무 종료를 막는다. 모의 회신을 원본 계약·설비 제약 변경 사실로 주장하지 않는다.
